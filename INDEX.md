## 🆘 Still Need Help?

### Check in this order:
1. **SETUP_CHECKLIST.md** - Most common issues
2. **QUICKSTART.md** - Quick troubleshooting
3. **README.md** - Advanced issues
4. Console logs in Xcode
5. Network logs from APIClient

### Common Error Messages:
- "Cannot find type" → Files not added to Xcode
- "Connection refused" → Backend not running
- "401 Unauthorized" → Token issue, re-login
- "Decoding error" → API response format mismatch
